# J.A.R.V.I.S. - Rule-Based AI Chatbot

A rule-based AI chatbot developed using Python as part of my Artificial Intelligence Internship at DecodeLabs.

## Project Overview

This chatbot simulates a simple AI assistant named J.A.R.V.I.S. using Python's conditional statements (`if-elif-else`) and loops. It responds to predefined commands and provides useful utilities while demonstrating the fundamentals of rule-based Artificial Intelligence.

## Features

- Personalized greeting
- Remembers user's name during the session
- Addresses users as Sir or Ma'am
- Time and Date
- Calculator
- Jokes
- Quotes
- Fun Facts
- Dice Roll
- Coin Flip
- Lucky Number Generator
- General Knowledge
- Help Menu
- Continuous Conversation Loop
- Rule-Based Decision Making

## How to Run

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/jarvis-rule-based-ai-chatbot.git
```

Go inside the project

```bash
cd jarvis-rule-based-ai-chatbot
```

Run

```bash
python chatbot.py
```
